# 人类技巧评级

## 参考方案

- [KyleGough/sudoku](https://github.com/KyleGough/sudoku)：将逻辑技巧与暴力求解区分，输出每步解释、技巧使用统计。
- [komeilmehranfar/sudoku-core](https://github.com/komeilmehranfar/sudoku-core)：TypeScript 的逐步技巧解题与逻辑可解题目生成。

采用“由简单到复杂寻找有效推理、维护消除后的候选、对解题路径评级”的设计。当前代码为本仓库独立实现，未复制上述实现，也未添加外部运行时依赖。等级是本地标准，不冒用其评级体系或其他平台的 Extreme 分数。

## 技巧与顺序

| 等级 | 技巧 | 规则 |
| --- | --- | --- |
| 1 | 显性单数、隐性单数 | 单格仅剩一个候选，或区域内某数字只有一个位置 |
| 2 | 区块排除 | 宫与行/列交集中锁定候选，向另一区域消除（指向和认领） |
| 3 | 显性/隐性数对、三数组 | N 格限制 N 数，或 N 数只能在 N 格，消除区域内相应候选 |
| 4 | X-Wing、Swordfish | 2/3 个基行（或列）的某数字限制在相同数量覆盖列（或行） |
| 4 | XY-Wing | 双值枢轴 XY，两个可见翼 XZ、YZ；共同看到两翼的格不能为 Z |

只有产生实际填入/消除才计步。每步之后重新从单数开始，不计空扫描。单数填入后的同行/列/宫消除属于该步的隐含效果。记录包含技巧、模式格、数字、填入、消除、原因。候选只会减少；不读取参考答案，不使用唯一性假设，不猜测。

## 接受条件与限度

生成器用独立回溯求解器确认唯一解。再要求低于 minRank 的逻辑解题器停滞、全技巧解题器成功，并比对最终答案。这样不会仅凭题目空格数量，或一次不必要的高级技巧应用，就判成难题。

默认 minRank=4。技巧顺序固定，报告是其中一条完整逻辑解法；不能据此断言报告中的每种高级技巧都是不可替代的。当前不支持四数组、链、染色、ALS 等，不能解出的题被拒绝。低阶停滞只针对本技巧库，不等价于所有人类低阶技巧均不可能奏效。

最多 400 个候选，预算 20 秒，每个候选前检查时间。预算用尽不会回退到简单题；UI 提示重试，已有进度不被替换。手机速度和随机命中率可能造成不同等待时间。

## 验证

- 固定种子生成不同题目并检查唯一解、完整逻辑解、低阶停滞。
- 随机样本和自生成固定题覆盖全部 10 种技巧；逐步重放，检查每次填入符合独立解、每次消除不删除正确答案、每区域仍有合法位置、最终棋盘与报告一致。
- 检查格式错误、冲突、完成棋盘、空棋盘停滞、预算失败不降级。
- 保存恢复时重新生成报告；旧题继续游戏，不追溯宣称已评级。
