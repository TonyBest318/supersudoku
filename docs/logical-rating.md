# L9 逻辑评级

## 引擎与等级

使用 MIT 授权的 [sudoku-core](https://github.com/komeilmehranfar/sudoku-core)，固定版本 4.1.1；npm lockfile 锁定包，构建包含许可证。所有代码运行于本地，离线也能生成 L9。

新游戏目标为正式 L9。该库按最高技巧的 rank 与累计技巧分数评定 L1–L10，工作量较大时可能上调一级，因此不能断言每道 L9 都必须使用某一种 L9 技巧。其 rank 5–6.8 对应 L9 技巧段；rank ≥7 进入 L10 技巧段。这是固定版本的规则，不是 sudoku.com 或 Sudoku Explainer 的分数。

| L9 技巧 | 作用 |
| --- | --- |
| Jellyfish | 四阶鱼形消除 |
| Finned Swordfish | 带鳍三阶鱼形消除 |
| Finned Jellyfish | 带鳍四阶鱼形消除 |
| BUG+1 | 在唯一解前提与特定候选结构下确定额外候选 |
| X-Chain | 同一数字的强弱链 |
| XY-Chain | 双值格链 |

L1–L8 技巧仍会优先应用。3D Medusa、AIC、Nishio 等 L10 技巧不允许出现在接受的新题解法里。

## 生成与验收

1. 生成随机种子，调用 `generate('L9', { seed, maxAttempts: 1, timeoutMs })`。库每次挖空均校验唯一解与人类逻辑评级。
2. 使用库的 `solve` 重新求解，要求成功、唯一、正式等级 L9，所有步骤为已知且 rank <7 的技巧。
3. 用本仓库独立回溯引擎确认唯一解，与逻辑结果比较；每个填入必须等于答案，每个消除不能删除答案。
4. 不合格继续生成。默认最多 500 个终盘、20 秒总预算；主线程 25 秒终止出题 Worker。失败提示重试并保留原局，不降级。

测试覆盖五个固定随机种子，独立唯一解校验、正式 L9 评级、每步候选重放、L10/未知技巧拒绝、预算耗尽和新旧存档恢复。旧版解题器仍有全部十种技巧覆盖测试。

## 显示与存档

报告 version=2、engine=`sudoku-core@4.1.1`，显示真实等级、技巧次数，终局后开放步骤中的模式格、填入与消除。L9 技巧附简短中文原理；上游步骤未完整暴露链的每条强弱边，当前不展示完整边证明。不存在游戏内提示按钮。

旧存档 version=1 使用原来的本地十技巧评级器恢复，显示旧题标记，不伪称 L9；无评级存档继续标为未评级。新游戏才切换至正式 L9。恢复时重算报告，不信任本地存储中的技巧计数或等级。

## 先前实现

旧版独立逻辑解题器参考了 [KyleGough/sudoku](https://github.com/KyleGough/sudoku) 的逐步解释思路。它提供单数、区块、数对/三数组、X-Wing、Swordfish、XY-Wing；旧版内部 rank 1–4 不等于 sudoku-core 的 L1–L4。新游戏不再使用该近似评级筛选。
